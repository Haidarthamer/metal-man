# Asset folders

The OBJ/texture files are distributed in the companion asset archive because the city mesh and texture are large.

Extract the archive at the repository root so these paths exist:
- `assets/armor/hero_ironman01.obj.gz` (gzip-compressed OBJ)
- `assets/armor/hero_ironman01.mtl` and the four referenced PNG maps
- `assets/city/ny_clean_up2.obj.gz` (gzip-compressed OBJ)
- `assets/city/tex.jpg`
- `assets/city/ny_clean_up2.mtl`

The city image is optimized to 4096px for mobile. Without the model files, the game still runs using its procedural suit and city blockout.
